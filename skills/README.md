# eliVibe

After your coding agent presents a technical handoff, use `$elivibe:elivibe` in Codex or `/elivibe:elivibe` in Claude Code to ask for a plain-language explanation. eliVibe explains how the parts fit together, why the change matters, and what the available evidence does not establish. It leaves the original report intact.

The plugin adds one prompt-only skill. It does not run scripts, start servers, change permissions, or send data on its own. The host handles the explanation in the current conversation using its normal processing and settings.

See the [installation guide](https://github.com/taibenvenuti/elivibe/blob/501223323cc4b32cdf4eb15cc62d737fda644db1/docs/installation.md) for your host, including first use, privacy, updates and removal.
